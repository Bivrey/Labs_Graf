# Лабораторная работа №3: PyQt + SQLite

Приложение для работы с SQLite-базами данных через графический интерфейс на PyQt5. Реализует выполнение SQL-запросов, просмотр метаданных и базовых данных, а также операции добавления и удаления записей.
